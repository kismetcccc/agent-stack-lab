# ADR 003：渐进式基础设施与独立验收

状态：首轮采纳。

决定：先核心任务闭环，再可选observability，最后Kind部署实验。对象存储、搜索、调度等扩展先列教学目标，不提前启动空壳容器。默认deterministic模型；真实依赖与真实模型是两个独立维度。

收益：单机可按章学习，错误来源更容易定位；没有模型key也能验收消息与数据库语义。

代价：第一版不是完整RAG/自主Agent产品；组件开启不代表能力完整；必须维护已实现/已验收/计划中的区别。

约束：不虚构最低硬件承诺。Compose与Kind不能仅凭YAML存在宣称通过；观察profile实测资源，避免默认同开两套全栈。Kubernetes只负责部署，不补齐业务一致性或数据库HA。
